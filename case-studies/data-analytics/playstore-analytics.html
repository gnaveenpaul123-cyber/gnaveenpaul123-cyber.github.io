Google Play Store Analytics Dashboard

An interactive Tableau dashboard that brings together Google Play Store app data in one exploration workspace. It enables users to compare app categories, install levels, ratings, pricing type, content ratings, and app-update trends through interactive filters, headline KPI indicators, and coordinated visual views.

Overview

The Google Play Store Analytics Dashboard is a comprehensive Tableau Public exploration workspace engineered to analyze the dynamics of the mobile application marketplace. By consolidating multidimensional app records into an interconnected dashboard layout, the project transforms dense tabular datasets into clear visual summaries. The dashboard provides stakeholders with immediate visibility into catalogue distributions, revenue drivers, market tiers, and release timelines across tens of thousands of application listings.

Problem & Objective

App-store datasets contain many overlapping dimensions: category, installs, rating, pricing model, content rating, reviews, and last-updated date. Looking at rows of data alone makes it difficult to identify how the marketplace is distributed, isolate growth segments, or compare categories under specific operating conditions.

The core objective was to design a unified Tableau dashboard that allows users to:

  • Filter the entire app catalogue dynamically by category, install bracket, pricing type, and content rating.
  • Monitor high-level summary KPIs for total installs, catalogue app count, free-versus-paid market mix, and average rating.
  • Identify high-volume categories leading the catalogue by total app counts.
  • Evaluate market monetization by exploring the distribution of free versus paid applications.
  • Examine app lifecycle and release momentum through trends by year of last update.
  • Compare category ratings, examine catalogue concentration across install brackets, and evaluate the relationship between user ratings and total installs.

What I Built in Tableau

  • Interactive Dashboard Filters: Global category, install bracket, pricing type (Free / Paid), and content rating dropdown filters that dynamically update all connected dashboard views.
  • Headline KPI Indicators: Clean executive indicator cards displaying total installs, total app volume, free app percentage share, and overall average rating across the active filter selection.
  • Category Volume Comparison: A horizontal bar chart displaying the Top 10 categories by total number of apps to highlight marketplace concentration.
  • Revenue & Monetization Ranking: A vertical bar chart ranking Top 10 categories by estimated revenue to identify key financial drivers.
  • Pricing Model Distribution: A Free vs Paid donut chart visualizing the proportion and app-count split between free and paid software models.
  • Release Momentum & Update Trends: A dual time-series line chart tracking app volume across years of last update, differentiated by app pricing type.
  • Category Rating Comparison: A structured bar chart comparing user rating distributions across app categories against marketplace baseline averages.
  • Install Bracket Treemap: A compact treemap displaying app-count distribution across segmented install tiers ranging from under 10K to 100M+ installs.
  • Rating vs. Installs Multi-Dimensional Analysis: A scatter plot correlating average ratings with total install volumes, using bubble size to represent review counts and color coding for install brackets and category details.

The dashboard was architected using specialized Tableau worksheets organized into an interconnected reporting canvas. The table below outlines the worksheet configurations, visual shelf placements, and analytical roles:

Calculated Fields & Helper Dimensions

To enable multi-tiered segmentation without distorting raw inputs, the workbook employs tailored Tableau calculated fields:

  • free vs paid — Segments application records into standardized pricing categories to power donut visualizations and split-series trends.
  • install bracket — Groups raw download numbers into structured adoption tiers (e.g., Under 10K, 10K–100K, 100K–1M, 1M–10M, 10M–100M), enabling cleaner cohort analysis and treemap sizing.
  • Rating Band — Partitions continuous rating values into analytical brackets for cohort evaluation and rating-distribution benchmarking.
  • Size Category — Classifies application footprint to assess the relationship between package size, user adoption, and device constraints.

Design Considerations

Consolidating Multi-Faceted Exploration in One Interface

Mobile market datasets are frequently fragmented across disparate reports. The dashboard integrates global dropdown filters for Category, Install Bracket, Type, and Content Rating directly adjacent to visual views. This enables rapid scenario testing—such as examining high-performing free productivity apps versus paid games—without requiring navigation across multiple tabs.

Balancing Volume, Quality, and Monetization Signals

Relying solely on install counts produces a biased picture of app health. The dashboard juxtaposes absolute install volume with review counts, user rating averages, and pricing distributions. This ensures that high-volume utility applications with modest ratings can be analyzed in contrast with smaller, highly-rated niche tools.

Visual Hierarchy & Cohesive Palette

To reduce cognitive load across eight simultaneous visual components, the design applies a restrained, professional slate-and-blue color palette. Key metrics are positioned at the top as immediate headline indicators, while deeper multi-variable relationships (such as the Rating vs. Installs scatter and Install Treemap) anchor the lower half of the view for secondary exploration.
